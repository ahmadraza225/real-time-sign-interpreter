# IMPORTANT - INSTALLING PYTORCH WITH CUDA SUPPORT
# -----------------------------------------------------------------------------
# The default `pip install torch` from PyPI installs a CPU-only build on
# Windows. To use the RTX 4060 Ti GPU you MUST install the CUDA-enabled
# wheels from PyTorch's dedicated index. Install torch/torchvision FIRST with
# the CUDA index-url, THEN install the rest of this file. For example:
#
#   # CUDA 12.1 build (recommended, widely compatible with RTX 40-series):
#   pip install torch==2.3.1 torchvision==0.18.1 --index-url https://download.pytorch.org/whl/cu121
#
#   # or CUDA 12.4 build:
#   pip install torch==2.4.1 torchvision==0.19.1 --index-url https://download.pytorch.org/whl/cu124
#
# See docs/CUDA_GUIDE.md for full details and verification steps.
#
# torch / torchvision are intentionally NOT listed as installable pins below.
# If they were, `pip install -r requirements.txt` would pull the CPU-only
# Windows wheels from PyPI and SILENTLY DOWNGRADE your CUDA build, killing GPU
# support. Install them yourself from the CUDA index-url (command above), then
# install this file. Any recent CUDA build works (e.g. 2.3.1+cu121, 2.4.1+cu124,
# 2.5.1+cu121); the project code is not tied to a specific torch version.
# -----------------------------------------------------------------------------
